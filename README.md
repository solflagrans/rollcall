# Rollcall

Rollcall — адаптивное веб-приложение для организации учебной группы и ведения посещаемости.
Оно объединяет учебные периоды, состав группы, дисциплины и занятия в одном спокойном и понятном
интерфейсе, одинаково удобном на компьютере и телефоне.

## Возможности

### Учебная группа

При создании группы выбирается привычная система учебных периодов: семестры, триместры,
четверти или учебные годы. Rollcall автоматически формирует названия периодов, определяет их
календарный статус и помогает избежать пересекающихся дат.

### Состав

Формирование состава начинается со старосты, после чего можно добавлять студентов и заместителей.
Участников можно редактировать, временно переводить в неактивный состав и возвращать обратно без
потери истории. Активный и неактивный состав отображаются отдельно.

### Дисциплины

У группы есть постоянный пул дисциплин. Одну дисциплину можно использовать в нескольких учебных
периодах, переименовывать, архивировать и восстанавливать. Для каждого периода выбираются только
те дисциплины, которые действительно изучаются в нём.

### Занятия и посещаемость

Занятие создаётся внутри выбранного учебного периода по подключённой дисциплине. Rollcall
фиксирует текущий активный состав, после чего можно быстро отметить каждого участника как
присутствовавшего, опоздавшего, отсутствовавшего или отсутствовавшего по уважительной причине.

Массовые действия заполняют только ещё не отмеченных участников и не перезаписывают ручные
решения. Для отдельной отметки можно добавить комментарий. Прогресс заполнения и завершённость
занятия рассчитываются автоматически, при этом занятие разрешено сохранить с частично заполненной
посещаемостью.

## Основной сценарий

1. Создать учебную группу и выбрать тип учебных периодов.
2. Добавить старосту и сформировать активный состав.
3. Создать общий пул дисциплин.
4. Добавить учебный период и подключить к нему нужные дисциплины.
5. Создать занятие и заполнить первичную посещаемость.

Группа, состав и дисциплины могут существовать до создания первого учебного периода, поэтому
подготовку можно выполнять в удобном порядке.

## Интерфейс

Rollcall использует адаптивную навигацию: на большом экране разделы группы находятся в боковом
меню, а на мобильном — в компактной верхней панели. Табличные представления на desktop заменяются
удобными вертикальными списками на небольших экранах. Доступны светлая и тёмная темы.

Интерфейс показывает понятные пустые состояния, мягкие предупреждения и конкретные сообщения об
ошибках. Архивирование и деактивация сохраняют данные, а потенциально опасные действия требуют
явного подтверждения.

## Текущий статус

Проект находится в активной разработке. Уже работают управление группой, учебными периодами,
составом и дисциплинами, а также создание занятия с первичным заполнением посещаемости.

Следующие этапы будут развивать журнал занятий, редактирование сохранённых отметок, статистику и
другие повседневные сценарии учебной группы.

## Технологии

Rollcall построен на Next.js и TypeScript. Данные хранятся в PostgreSQL на Neon и управляются через
Drizzle ORM. Интерфейс использует Tailwind CSS, shadcn/ui и адаптивную дизайн-систему проекта.
